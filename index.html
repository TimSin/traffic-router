Settings

HERE API key

The key is used only for requests from this page to HERE. If you tick "Remember in this browser", it is kept in this browser's local storage and nowhere else. You can create a key at platform.here.com.

Road preference

Charges

Charges come from HERE and are estimates. Showing them makes each route request count as two HERE requests.

TfL disruptions

TfL's data is free and doesn't count against HERE. The app fetches it at most every 5 minutes. Without a key TfL limits anonymous use, so the app stops at 400 requests a day; a free key from api-portal.tfl.gov.uk removes that.
